🖼️ From noise to image

When you write “mountains at sunset, poster style” and get an image seconds later, it seems as if the AI found the picture somewhere. It didn't. It created it from scratch. Most current image generators start with a screen full of random dots—like the static on an old TV—and gradually clean up the mess, step by step, in the direction described by your text.

🌱 New here?

Diffusion model is a type of AI that learned to remove noise from images. During training, it saw millions of photos and drawings with descriptions and learned the way back: from blur to a clear image. Noise is that random grain at the start. Visual prompt is the description you write—it guides each step of the cleanup.

What it is

AI image generation creates a new picture from text (or a reference image). The model doesn't copy an existing photo: it assembles pixels that fit the patterns it learned and what you asked for.

✓ The generator does well

  • ✓Illustrations, settings, and visual concepts for posts and presentations.
  • ✓Quick variations on an idea for you to choose from.
  • ✓Backgrounds, textures, and product scenes for testing a layout.

✗ Still requires care

  • ✗Hands, small text, and objects with many repeating parts.
  • ✗A real product with exact details (label, logo, measurements).
  • ✗Anything that needs to be accurate, such as a photo of an event.

Why learn

Knowing that an image emerges from noise guided by text explains why the same sentence produces different results, why fine details fail, and why a well-described request saves attempts. You stop “leaving it to chance” and start directing.

Key concepts

Diffusion
remove noise until the image
Visual prompt
the description that guides it
Generation
a new image, not a search
Gap
what you don't say, the model invents

🧱 Anatomy of a visual request

There are lists with dozens of visual prompt “categories.” You don't need to memorize any of them. In practice, a request that works answers six questions, in order of importance: what appears, where, in what style, with what lighting, from what angle, and in what format. Think like a cinematographer describing the scene to the crew.

What it is

The anatomy of a visual request is a fixed order of six layers—subject, setting, style, lighting, composition, and format with constraints—that covers what the model needs to know so it doesn't fill in the gaps on its own.

Vague requestWhat the model inventsDirected request
“a bakery”Angle, era, style, people, mood.“neighborhood bakery counter at 6 a.m., bread in the display case, realistic photo, warm light, wide shot, 16:9”
“modern logo”Colors, shape, typeface, icon.“simple stylized leaf icon, single-line drawing, green and white, plain background, no text”
“happy person”Age, clothes, place, exaggerated expression.“40-year-old woman laughing at a conversation in a café, candid photo, window light”

Goal: turn a loose idea into a visual prompt with the six layers.

You are an art director. I want an image for <where it will be used: post, cover, presentation>.
My idea, just as it came to me: <describe it in one or two sentences>

1. Ask me up to 3 questions about what is unclear.
2. Then write the final prompt in English, in one paragraph, in this order:
   subject, setting, style and medium, lighting, composition, format and constraints.
3. Also write a short version (up to 25 words) of the same prompt.
4. List 2 different style variations for me to compare.

How to check: the final prompt needs all six layers—mark each one with your finger. Generate the image with the long and short versions; if the short one comes out almost the same, the extra layers weren't needed. If it comes out very different, that's where your intention was.

Why learn

A fixed six-layer outline works with any tool, now and in the next version. It reduces attempts, makes results more predictable, and can also help you explain the idea to a human designer.

Key concepts

Subject
who or what appears
Composition
angle and framing
Aspect ratio
1:1, 4:5, 9:16, 16:9
Constraints
what should not appear

🧰 Tools by task

The list of image tools changes every month, and the name of the “best generator” changes just as often. Instead of chasing the latest thing, start with the right question: what's the task? Creating from scratch, changing a photo you already have, adding legible text to an image, or running everything on your own computer are different jobs, and different tools are better at each one.

What it is

It's a map of four visual tasks—creating from scratch, editing with instructions, transforming one image into another, and generating locally—with examples of well-known tools for each. Names and prices change; the tasks stay the same.

TaskTool examplesWhen to use it
Create from scratch (text → image)ChatGPT, Gemini, Midjourney, Ideogram, FLUXIllustration, concept, scene for a post or slide.
Edit with instructionsChatGPT, Gemini, AI photo editors (such as Photoshop with generative fill)“Replace the background with a beach,” “remove the person in the background.”
Image → imageThe same generators, with a reference photo uploadedKeep the pose, product, or character and change the style.
Generate on your computerStable Diffusion and FLUX in programs such as ComfyUIHigh volume, privacy, fine control—it requires a good graphics card.

🌱 New here?

Open model is a model whose file you can download and run on your computer, such as several versions of Stable Diffusion and FLUX. Graphics card (GPU) is the computer component that handles the heavy calculations for generation. License is the document that explains what you can do with the model and the images—read it before using them for work.

💬 In chat

The easiest way to get started: you chat, ask for changes in English, and the image changes. Good for people who already use ChatGPT or Gemini every day.

🎛️ Dedicated generator

More control over style, aspect ratio, and variations. It's worth it when images are a big part of your work.

🖥️ Local

No sending files elsewhere and no per-message limit. It requires installation and a powerful computer; it's the next step, not the first.

💡 Tip

Test the same prompt in two tools before choosing one. Save both images side by side with the tool names. In ten minutes, you’ll find out which one suits the kind of piece you’re making—without relying on someone else’s rankings.

Why learn

Choosing by task helps you avoid subscribing to three services that do the same thing and avoids forcing a tool to do something it does poorly. When a new generator appears, you’ll know which row of the table it belongs in.

Key concepts

Text to image
create from scratch
Instruction-based editing
change it with one sentence
Open model
runs on your computer
License
what’s allowed

🔁 Consistency and editing

A single beautiful image is easy. The hard part is the second one: the same mascot in another pose, the same color palette in the next post, the same product in a different setting. Since each generation starts from new noise, without care each image comes out related to the previous one, but not identical. That doesn’t work for a brand or a series.

What it is

Consistency means keeping the character, product, style, and color palette the same across multiple images. You can do this with a fixed reference image, a reusable base description, and targeted edits instead of generating everything again.

Character sheet. Write a fixed base description: "Lia, the store’s mascot, an orange fox with a green scarf, flat illustration, thick lines." Paste this into every request.

Reference image. Choose the best version and include it with your next requests ("keep this character, change only the pose").

Area editing. Select the problem area and describe only the correction ("hand holding the cup by the handle").

Upscaling. Finally, increase the resolution with the tool’s upscale function so the image stays sharp in print or on a large screen.

🌱 New here?

Inpainting is the technical term for editing an area: you paint over the part you want to change, and the model redraws only that area. Upscaling means enlarging the image while adding detail, instead of simply stretching the pixels. Seed (seed) is the number that determines the initial noise; some tools let you reuse the same seed to get a similar result.

✓ Keeps the series consistent

  • ✓Paste the character’s base description without changes.
  • ✓Use the same reference image for every request.
  • ✓Describe the palette using fixed color names.

✗ Breaks the series’ consistency

  • ✗Describe the character with different words each time.
  • ✗Regenerate the entire image because of one detail.
  • ✗Mix different tools in the same series without a reference.

Why learn

A brand is recognized through repetition: the same colors, the same style, the same character. Without consistency, AI generates disconnected assets; with it, you can build a visual identity that lasts for months and that your audience recognizes from a distance.

Key concepts

Reference
image that locks in the look
Base description
repeated description
Inpainting
edit just one area
Upscaling
upscale with added detail

🎬 AI video and audio

Video generators use the same idea as image generators, but they also need to maintain consistency from frame to frame. That’s why they produce short clips, just a few seconds long, rather than an entire film all at once. A finished video is made by combining several clips, narration, and a soundtrack—and you’re still the one directing it.

What it is

AI video means generating clips from text or a starting image, creating narration with a synthetic voice, adding a soundtrack and effects, and editing it all together. It also includes talking avatars that read a script as a virtual person.

🎥 Clips

Generators like Veo, Kling, Runway, and Sora create short scenes from text or an image.

🧑‍💼 Avatars

Services like HeyGen and Synthesia have a virtual person read your script.

🎙️ Voice

Synthetic narration (such as ElevenLabs) and automatic transcription (such as Whisper) for captions.

🎵 Music and effects

Soundtrack generators (such as Suno) and sound effect libraries with clear licensing.

✂️ Editing

Common editors like CapCut and DaVinci Resolve already include cuts and automatic captions.

📐 Format

Decide in advance: 9:16 for Reels and Shorts, 16:9 for YouTube and presentations.

Try this: turn a short video idea into scenes ready to generate.

I want a vertical video (9:16), <30 to 45> seconds long, about: <your topic or product>.
Audience: <who will watch>. Tone: <serious, light, educational>.

Create a scene table with these columns:
Scene | Duration | Narration (short sentence) | Starting image prompt | Camera movement
Rules:
- Start with a strong hook in scene 1, without overdoing it.
- No more than 6 scenes.
- Image prompts should include the subject, setting, style, lighting, and composition.
- Always use the same base description for the character: <fixed description>.
At the end, suggest a soundtrack (style and tempo) that won’t compete with the voice.

How to check: Some of the durations—the total should match what you requested. Read only the narration column out loud: it needs to make sense on its own. Check that the character’s base text appears the same in every scene.

Why learn

Short video is the format that circulates most on social media, and making one used to require a camera, a crew, and editing. With the workflow script → keyframe → clip → assembly, one person can make a decent piece—provided they direct each step.

Key concepts

Clip
short generated scene
Key frame
image that starts the scene
Avatar
virtual person who speaks
Editing
combine clips, voice, and music

⚖️ Rights, faces, and labels

Generating is easy; publishing requires responsibility. Three questions address most problems before they happen: Do the tool’s terms allow this use? Does the image use someone’s face, voice, or brand? Could the audience be misled into thinking it’s real? Copyright law and rules about AI are under discussion in several countries, including Brazil, so caution is better than a shortcut.

What it is

A set of precautions for using generated images and videos without violating others’ rights: respect terms of use and licenses, don’t use someone’s face or voice without permission, avoid other people’s brands, and disclose when content is synthetic.

SituationRiskSafe approach
Real person’s faceImage rights and personal data (LGPD (Brazil’s data protection law)).Only with the person’s written permission.
Cloned voiceFraud and identity misuse.Use only your own voice or licensed voices.
“In the style of” a living artistEthical conflict and public complaints.Describe the style in words (linework, color, era), without naming anyone.
Logo or famous characterTrademark and copyright.Create your own elements.
Scene that looks like newsMisinformation.Label it as AI-generated or don’t publish it.

✓ Do

  • ✓Read the commercial-use terms of the tool you use.
  • ✓Save the prompt and date for each image you publish.
  • ✓Label synthetic content when it could confuse someone.

✗ Don’t

  • ✗Put a client, colleague, or celebrity in a scene without permission.
  • ✗Sell a generated product image as a “real photo.”
  • ✗Remove a watermark or label indicating generated content.

💡 Tip

Several platforms already ask you to label AI-generated content when you publish, and some tools embed an invisible label in the file. Instead of seeing this as an obstacle, use transparency to your advantage: “AI-generated illustration” doesn’t take away from a thoughtfully made post.

Why learn

A piece that violates image rights or misleads the public can cost far more than it saved: removal, a lawsuit, and loss of trust. These precautions take minutes and protect you and your brand.

Image rights

🛠️ From brief to finished piece

Now put it all together in a real piece. The secret to working well with visual AI isn’t a magic prompt: it’s having a brief before generating and a review before publishing. AI comes in the middle, speeding up your attempts.

What it is

A complete exercise: write a short brief, ask the assistant for three different visual prompts, generate the images, choose one, make any needed corrections, and run through a review checklist before publishing.

Step 1 · Brief. Answer in a few lines: who it’s for, where it will be used, the message, the mood, and the format.

Step 2 · Three directions. Use the prompt below to get three different visual directions.

Step 3 · Generate and choose. Generate each prompt once or twice and choose the image that best conveys the message—not the prettiest one.

Step 4 · Correct. Edit only the problem area and increase the resolution.

Step 5 · Review. Go through the review checklist in the second block before publishing.

Goal: leave the brief with three visual directions ready to generate.

You are an art director at a small agency.
Brief:
- Audience: <audience>
- Where it will be used: <Instagram post, presentation cover, website banner>
- Main message: <one sentence>
- Desired mood: <confidence, joy, urgency, calm>
- Format: <1:1, 4:5, 9:16, or 16:9>
- Brand colors: <if any>

Create 3 visual directions that are truly different from one another (for example: realistic photo, illustration, graphic composition).
For each one: direction name, why it conveys the message, and the complete prompt
(subject, setting, style and medium, lighting, composition, format, and constraints).
Don’t include written text inside the image; I’ll add the text afterward.

How to check: The three directions need to be genuinely different—if two look like the same idea in different colors, ask “redo direction 2 with a different concept.” Each prompt should include all six layers and repeat the format you requested.

Try this: ask for a critical review of the chosen image before publishing.

[attach the chosen image]
This image will be used <where> for <audience>, with the message <message>.
Review it as a demanding art director and respond in a list:
1. Visible flaws (hands, faces, deformed objects, nonsensical letters).
2. Whether the image conveys the message in 3 seconds. Why?
3. Anything that could look like a real photo of a person, brand, or existing event.
4. Where I can place the text without covering the main subject.
5. The single correction that would most improve the piece.

How to check: Check every flaw listed in item 1 yourself too—the AI may miss one or point out something that isn’t there. If item 3 raises any doubt, return to topic 6 before publishing.

Why learn

The brief and review are what separate a generic image from a piece that communicates. Completing the whole cycle once with one of your own pieces helps you learn the method and gives you a model for all the next ones.

Key concepts

Brief
the request before the prompt
Visual direction
a stylistic approach
Review
critical look before publishing
Message
