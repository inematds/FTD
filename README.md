## 📚 SOBRE O PROJETO

O **FTD (Formação da Transformação Digital)** é um curso super avançado que capacita pessoas a compreenderem e se posicionarem estrategicamente na transformação digital que estamos vivendo.

### 🎯 Missão
Proporcionar um **caminho rápido e profundo** de conhecimento sobre IA, automação e tecnologias emergentes, preparando profissionais para o mercado de 2025+.

## 🏗️ STACK TECNOLÓGICO

### Frontend:
```
Next.js 14 (App Router) + TypeScript
Tailwind CSS + shadcn/ui
Framer Motion (animações)
Plyr.io (player de vídeo)
```

### Backend:
```
Supabase (BaaS)
  ├── Authentication (Auth)
  ├── Database (PostgreSQL)
  ├── Storage (Arquivos/Vídeos)
  └── Realtime (Chat, Comentários)
```

### Pagamentos:
```
Stripe (Cartão + Pix)
Webhooks para ativação automática
```

### Hospedagem:
```
Vercel (Frontend - deploy automático)
Cloudflare (CDN + Performance)
```
